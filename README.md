# 取镜核对台（老花镜 / 渐进镜）

面向领取老花镜、渐进镜时**难以核对处方缩写**、且**容易把左右眼镜袋拿反**的中老年配镜者的纯前端 Web 核对台。
分别抄录 **验光处方 / 加工单 / 镜片包装（镜袋）** 上的 OD（右眼 R）、OS（左眼 L）的
SPH（球镜）、CYL（柱镜）、AXIS（轴位）、ADD（下加光）、单眼 / 双眼瞳距，
应用以左右“镜框卡”逐项展示 **原值 → 规范值 → 差异**，并提示**疑似左右互换**。

**隐私：** 所有抄录数据与凭据图片只保存在本机浏览器（IndexedDB），不向任何服务器发送；
页面为纯静态站点，`npm run dev` 仅在本机 `127.0.0.1` 监听。

## 启动

```bash
npm install
npm run dev
```

然后在浏览器打开终端中提示的地址（默认 http://127.0.0.1:5173 ）。
刷新页面会自动恢复未完成的核对。

## 核对规则（只做“单据一致性”核对，不评价处方是否适合佩戴）

1. **正 / 负柱镜等价记法**：SPH+CYL+AXIS 作为一个球柱镜组联合比较。
   写法不同但等价时（如处方 `-2.00 / -1.00 × 180`，镜袋 `-3.00 / +1.00 × 90`），
   按转写规则给出逐步依据：① 新球镜 = 球镜 + 柱镜；② 新柱镜变号；③ 轴位 ±90°。
2. **轴位按 180° 周期比较**：0° 与 180° 等价，5° 与 175° 的环形差为 10°。
3. **缺失不补齐**：标记为“看不清 / 未提供”的字段不参与判定，灰色显示“无法判定”，
   绝不拿缺失值凑出“一致”结论。
4. **疑似左右互换**：本侧（右对右、左对左）不符，而交叉（A.右对B.左、A.左对B.右）后相符时，
   弹出橙色提示并展示逐步数值依据；**仅作提示，必须由用户人工确认**。
5. **确认立即作废**：确认后再改动任何抄录 / 容差 / 镜种（含撤销恢复），旧结论立即标记为“已作废”。
6. **交接单 JSON**：仅含来源、争议字段（原值 + 差异说明）、互换嫌疑、确认状态与时间；
   不含完整处方、不含图片、不含适配性评价。

## 支持的抄录写法

| 字段 | 可识别写法举例 |
| --- | --- |
| 球 / 柱 / ADD | `-1.25`、`+2.00`、`+200`（= +2.00D）、`-025`（= -0.25D）、`-1.25DS`、`PL / plano / 平光` |
| 轴位 | `180`、`005`、`5`、`175°`（0 自动按 180 处理） |
| 瞳距 | `62`、`32.5`、`62mm` |

注意：无符号的 1–2 位数字（如 `90`）无法区分是度数还是轴位，不予猜测，请照写 `+0.90` 或改标“看不清”。

## 技术栈

React 18 + TypeScript + Vite 5，状态持久化使用 IndexedDB（`kv` 存抄录、`images` 存凭据 Blob），
无后端、无第三方运行时依赖。

目录：

- `src/lib/optics.ts` — 原文解析、球柱镜转写、轴位周期差
- `src/lib/compare.ts` — 三来源核对引擎、互换检测、指纹、交接单生成
- `src/lib/db.ts` — IndexedDB 封装
- `src/lib/state.ts` — 撤销历史与自动持久化
- `src/components/` — 录入表、左右镜框卡、凭据图片灯箱
- `scripts/check-logic.ts` — 核对规则的离线验证脚本（`npx esbuild scripts/check-logic.ts --bundle --platform=node --format=cjs | node`）
